# 油壓缸管理系統（CYL）

手機優先的油壓缸設備管理工具。設備資料使用瀏覽器 IndexedDB 儲存在目前裝置，不會傳送到 GitHub 或雲端。

## 功能
- 兩座加熱爐、四個區域、16 個線上位置；每區位置由左至右為 4、3、2、1。
- 油壓缸新增、編輯、狀態管理與停用。
- 安裝、拆卸與更換時建立使用期間。
- 以日曆天計算使用天數，不含安裝當天。
- 累積使用時間、排行、備品與維修管理。
- 異動歷史、JSON 匯出與還原。
- Service Worker 離線快取。

## 使用方式
1. 將本 Repository 的檔案部署到支援 HTTPS 的靜態網站（例如 GitHub Pages），或在支援的本機 Web Server 上執行。
2. 首次開啟時讓頁面載入完成；Service Worker 安裝後，已快取的介面可離線開啟。
3. iPhone 使用 Safari 開啟 HTTPS 網址，使用「分享」→「加入主畫面」。
4. 建議先建立少量測試設備，確認安裝、拆卸、備品與維修流程，再輸入正式資料。

> 注意：PWA 的 Service Worker 需要 HTTPS（localhost 開發環境除外）。若只用檔案管理器直接開啟 index.html（file://），IndexedDB 可能可用，但離線快取與加入主畫面功能不保證可用。

## 資料安全
- 所有資料存在目前手機的瀏覽器儲存空間。
- GitHub 僅保存程式碼，不保存設備資料。
- 清除 Safari 網站資料、瀏覽器重設或更換手機可能導致資料遺失。
- 請定期使用「資料備份」匯出 JSON，並將檔案另存到安全位置。
- 不同手機／瀏覽器之間不會自動同步。

## 使用時間規則
- 使用天數 = 拆卸日期 − 安裝日期；不含安裝當天。
- 安裝當天顯示 0 天。
- 尚未拆卸的使用期間以今天計算。
- 備品、維修中、待檢查等非使用狀態不增加使用時間。
- 累積使用時間為所有已結束期間加上目前使用期間。
